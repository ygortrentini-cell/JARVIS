## O que mudou

- Ativa por padrão o Modo de Melhoria Completa para receber atualizações do JARVIS e da interface pelas Releases oficiais.
- Substitui o código do aplicativo por versão e permite remover módulos Python antigos quando uma Release os retirar.
- Permite pausar atualizações definindo `MODO_MELHORIA_COMPLETA = False` em `config.py`.
- Preserva dados, memória, configurações, registros e modelos de voz locais durante as atualizações.

## O que aprendeu

- O JARVIS informa as melhorias e novidades descritas nas notas de cada Release.
- As mudanças vêm de versões publicadas no repositório oficial; o JARVIS não gera nem executa alterações de código por conta própria.
